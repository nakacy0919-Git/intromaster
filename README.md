# INTRO MASTER

テレビの音楽クイズ番組をイメージした、個人利用向けのブラウザーアプリ。

## 起動（Windows / VS Code）

```powershell
git clone https://github.com/nakacy0919-Git/intromaster.git
cd intromaster
py -m http.server 8000 --bind 127.0.0.1
```

ブラウザーで http://localhost:8000/ を開く。すでにクローン済みの場合は main を pull する。Python がない場合は VS Code の Live Server 等を使う。YouTube の参照元識別のため file:// で直接開く方法は推奨しない。

## 機能

- オリジナル合成音の10曲デモ。架空の曲名・独自順位で、インターネット接続不要。
- 昭和・平成・令和、1970〜2020年代、発売年別、ジャンル別、全曲。
- 登録順位順のカウントダウン / ランダム、5・10・20曲設定（登録曲数が上限）。
- 1・3・5・10秒のイントロ、正解発表、指定サビ、結果画面。
- 4チームの名前と得点、司会者ショートカット、全画面表示、効果音の切替。
- 公式YouTube動画のURL、発売日、独自順位、イントロ位置とサビ位置の登録・編集・削除。プレビュー中の現在位置を取得。
- ブラウザーの localStorage に保存。JSONでバックアップ・インポート。

## YouTube の利用

YouTube IFrame Player API を使用。公式プレーヤーは常時表示し、映像やタイトル、広告、コントロールを隠さない。音源のダウンロード・抽出・保存は行わない。埋め込みが無効な動画、広告やブラウザーの自動再生制限、キーフレームによる開始位置の差があり得る。動画によってタイトルや映像で正解が見えることがある。

デモ曲は既存音源ではなく、ブラウザーで生成するオリジナル合成音。昭和・平成・令和の実集計に基づくカラオケランキングを搭載。昭和カラオケTOP10は、JOYSOUND「昭和100年」総合ランキング（2024年1月1日〜10月31日集計）を参照した曲名・歌手・順位・動画IDを登録済み。その他の登録順位は利用者独自の順位。講演・イベントで実際の音楽を再生する場合は権利と利用規約を確認する。

- https://developers.google.com/youtube/iframe_api_reference
- https://developers.google.com/youtube/terms/developer-policies
- https://www.youtube.com/t/terms

## 配信

現時点では静的HTMLのみ。VercelやGitHub Pagesへのデプロイは行わない。リポジトリ自体の公開範囲はGitHubの設定で管理する。個人用の楽曲ライブラリーJSONは公開リポジトリにコミットしないこと。

## 昭和カラオケ TOP 10

ランキング出典: https://www.joysound.com/web/s/karaoke/feature/showa100

ホーム画面の専用ボタンは順位10→1で固定。初回起動時に既存データを保持して10曲を楽曲管理にも追加する。公式配信の動画IDを利用し、フレンズはライブ版、アンパンマンのマーチは公式テレビサイズ版を採用。I LOVE YOUは1983年のアルバム初出（シングルは1991年）。動画ページの確認と実際の再生可否は異なる。埋め込み動作は未検証。

イントロは各動画の0秒を初期値として1・3・5・10秒再生可能な設定。実際の音の開始位置は未試聴のため調整が必要な場合がある。サビの位置は未測定のため未設定。正解発表後、公式プレーヤーでサビへ移動し「現在位置をサビに保存」を押すとローカル保存される。楽曲管理でも両位置を変更可能。

## 平成・令和の追加ランキング

- 平成：JOYSOUND 平成カラオケ総合ランキング（1993〜2018年の歌唱集計）TOP10。10位の尾崎豊 I LOVE YOU は昭和発売のため昭和リストと動画設定を共有。https://www.joysound.com/web/s/karaoke/feature/heisei/ranking
- 令和：JOYSOUND 2025年年間総合ランキングから令和発売の10曲を抽出した独自の絞り込みランキング。元の総合順位（1, 2, 5, 8, 10, 11, 13, 16, 19, 21）も正解発表時に表示。令和全期間の総合順位ではない。https://www.joysound.com/web/s/karaoke/contents/annual_ranking/2025
- 初回更新時に19曲を既存の楽曲ライブラリーへ追加。設定済みの再生位置・動画IDを上書きしない。動画開始は0秒初期値、サビ位置は未測定。公式MV・配信音源・ライブ版などを利用。実機での再生可否と開始秒数は未検証。
- GitHub Pagesで公開する場合、ランキングデータの利用条件を確認し、必要に応じて許諾を得る。楽曲ファイルは保存・配信しない。
